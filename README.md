# sravanthi pachipala — Portfolio

A cinematic dark editorial single-page developer portfolio showcasing data analytics and machine learning projects.

**Live site**: [https://YOUR-SITE-URL/](https://YOUR-SITE-URL/)

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Tech Stack
- React 19
- Vite
- Tailwind CSS 4
- GSAP + ScrollTrigger
- EmailJS

## Run Locally
1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Environment Variables
Create a `.env.local` file in the root directory to enable contact form delivery:
- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`
